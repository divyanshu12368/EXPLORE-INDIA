# 🇮🇳 EXPLORE-INDIA

A React-based web application for exploring and discovering India's rich cultural, historical, and geographical diversity.

## Overview

EXPLORE-INDIA is a modern frontend application built with React and Vite, designed to provide users with an interactive platform to explore various destinations and information about India. The project showcases best practices in React development with component-based architecture, routing, and state management.

## Features

- 🗺️ **Interactive Exploration** - Browse and discover destinations across India
- 🎨 **Modern UI** - Built with React and styled using Tailwind CSS and Styled Components
- 🔐 **Authentication** - User authentication system for personalized experience
- 📱 **Responsive Design** - Optimized for desktop and mobile devices
- ⚡ **Fast Performance** - Powered by Vite for rapid development and optimized builds
- 🎯 **Component-Based** - Modular architecture with reusable components

## Tech Stack

- **Frontend Framework**: React 19.2.0
- **Build Tool**: Vite 7.2.4
- **Styling**: 
  - Tailwind CSS 4.2.1
  - Styled Components 6.3.8
- **Routing**: React Router DOM 7.13.0
- **Icons**: Lucide React 0.577.0
- **Linting**: ESLint 9.39.1
- **Development**: Node.js with npm/yarn
